Paste in research

Takes one finding, a list of them, or a full Shopwatch export. Anything you set by hand stays as you left it, and the result tells you what was kept. 


  

  

    
    
  




  
Research access

  

    

      Product suggestions and retailer research run on the Shopwatch host through its
      Claude Code CLI session and web search. Shopwatch does not use an
      API key or paid OpenRouter fallback, and does not expose the session to this app.
    

    

      The host operator must keep the CLI signed in and verify its subscription and
      WebSearch access. If a job asks for reconnection, sign Claude Code in again on
      the host and retry it from the wizard. Direct retailer checks continue while
      research is unavailable.
